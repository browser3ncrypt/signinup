Media Hosting • Cloudflare R2

Host Videos & Photos for Free on Your Website (Cloudflare R2 + Pages)

Store and serve unlimited media files with excellent performance and no egress fees.

Why This Stack?

  • Completely free for moderate usage
  • Global CDN with low latency
  • No egress fees (unlike AWS S3)
  • Easy integration with Cloudflare Pages

Step-by-Step Guide

1

Create an R2 Bucket

Go to Cloudflare Dashboard → R2 → Create Bucket. Give it a name like my-media-bucket.

2

Upload Files

Use the R2 dashboard or Wrangler CLI:

wrangler r2 bucket create my-media-bucket
wrangler r2 object put my-media-bucket/videos/demo.mp4 --file ./demo.mp4
3

Make Files Public

In R2 settings, enable public access or use custom domain + CORS rules.

4

Deploy Static Site on Pages

Use Wrangler or Git integration to deploy your HTML site that references R2 files.
